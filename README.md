# WorkshopOS

Premium automotive workshop management SaaS platform.

## Current status

Foundation stage.

## Requirements

.NET 10 SDK

## Development

```bash
dotnet tool restore
dotnet restore
dotnet build WorkshopOS.slnx
dotnet run --project src/WorkshopOS.Web
```

## Database

PostgreSQL integration is planned but database provisioning has not yet been applied.

## Cross-platform

Development targets macOS and Windows using standard .NET CLI workflows.
