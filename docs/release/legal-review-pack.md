## Counsel decision checklist

### Must close before commercial distribution

- [ ] **Commercial brand clearance** completed or alternate market name selected
- [ ] Final license agreement / `LICENSE` instrument
- [ ] Governing law and venue
- [ ] Warranty disclaimer and scope
- [ ] Liability limitations and caps
- [ ] Indemnity scope
- [ ] Derivative work / customer modification ownership
- [ ] Assignment and M&A transfer language
- [ ] Termination and cure periods
- [ ] Order form / SOW alignment with entitlements
- [ ] Trademark / white-label exhibits (if offered)
- [ ] Third-party license compatibility review (incl. OFL font)
- [ ] Security contact publication

### Owner commercial decisions (non-legal drafting)

- [ ] Official domain
- [ ] Pricing and maintenance tiers
- [ ] Default licensed location allowance
- [ ] Support tier definitions
- [ ] Partner/reseller program (if any)
