## Required clearance activities (for next candidate)

### 1. Exact-name web search

- [ ] Search engines for exact `"<candidate>"` and close variants
- [ ] Review top results for **automotive / workshop / fleet / repair-shop software**
- [ ] Record conflicting product names, domains, and company identities (outside repository)
- [ ] Assess likelihood of customer confusion in target markets

### 2. Relevant software / automotive market search

- [ ] Broader search in automotive workshop management category
- [ ] App store / marketplace search (if applicable to distribution channel)
- [ ] Industry directory / SaaS listing review
- [ ] Note confusingly similar names (not only exact matches)

### 3. Domain availability review

- [ ] Primary `.com` and country TLD candidates reviewed
- [ ] Defensive variants considered (hyphenation, common misspellings) — owner decision
- [ ] **Do not register domains** until legal/commercial direction confirmed
- [ ] Security contact domain aligned with final brand domain

### 4. Company / business-name review

- [ ] Licensor legal entity name selected
- [ ] Selling entity matches contract parties
- [ ] No unintended conflict with existing company registrations (owner/counsel)

### 5. Official trademark database search (target territories)

**LEGAL COUNSEL / TRADEMARK AGENT REQUIRED**

- [ ] Identify target countries/regions of commercial distribution
- [ ] Search official trademark registers per territory
- [ ] Review pending applications, not only registered marks
- [ ] Document search date, databases used, and results summary

Official systems:

| System | URL |
|--------|-----|
| WIPO Global Brand Database | https://www.wipo.int/branddb/en/ |
| TÜRKPATENT Marka Araştırma | https://www.turkpatent.gov.tr/ |
| EUIPO / TMview | https://www.tmdn.org/tmview/ |
| USPTO Trademark Search | https://tmsearch.uspto.gov/ |

### 6. Nice Classification review

**LEGAL COUNSEL / TRADEMARK AGENT REQUIRED**

**CLASSIFICATION MUST BE VERIFIED BY TRADEMARK PROFESSIONAL BASED ON FINAL GOODS/SERVICES DESCRIPTION.**

Likely relevant classes for workshop software (confirm with counsel):

| Class | Possible relevance |
|-------|-------------------|
| Class 9 | Computer software, SaaS platforms |
| Class 42 | Software as a service, hosting, technical services |

- [ ] Classes for target territories identified
- [ ] Similar marks in relevant classes reviewed

### 7. Confusing-similarity review

- [ ] Visual similarity (logo/wordmark)
- [ ] Phonetic similarity
- [ ] Conceptual similarity
- [ ] Related goods/services overlap
- [ ] Channel overlap (B2B automotive software)

### 8. Final legal clearance decision

- [ ] Counsel written opinion or internal risk acceptance documented
- [ ] Decision: **Proceed with cleared alternate brand** (WorkshopOS is not cleared)
- [ ] If alternate brand: execute [commercial-rebrand-playbook.md](commercial-rebrand-playbook.md)
- [ ] Update [brand-governance.md](../product/brand-governance.md) with outcome
- [ ] Only then configure `security@<official-domain>` in SECURITY.md
