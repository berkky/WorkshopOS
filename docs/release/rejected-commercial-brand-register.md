# WorkshopOS Rejected Commercial Brand Register

**Purpose:** Master register of names **rejected from the WorkshopOS commercial naming process**.  
**Status:** Governance record — **not legal advice** and **not a trademark clearance opinion**.  
**Effective:** STEP 24.5 — automated Cursor naming rounds **FROZEN**.

---

## How to read this register

| Column | Meaning |
|--------|---------|
| **Name** | Exact candidate or working name evaluated |
| **Round** | WorkshopOS collision · Round I · Round II · Round III |
| **Reason category** | Internal screening classification (see below) |
| **Status** | Always **REJECTED FROM WORKSHOPOS COMMERCIAL NAMING PROCESS** |

### Reason categories (non-legal)

| Category | Use when |
|----------|----------|
| **EXACT ACTIVE BRAND** | Exact or near-exact active commercial use in target category |
| **TECH/SOFTWARE COLLISION** | Active or prominent technology/software/platform collision signal |
| **AUTOMOTIVE/WORKSHOP ADJACENCY** | Collision or confusion risk in automotive, workshop, fleet, or repair software |
| **PHONETIC/VISUAL CONFLICT** | Confusingly similar spelling or sound to existing mark |
| **GEOGRAPHIC/COMMON NAME** | Surname, place-name, or common proper-name character |
| **LOW DISTINCTIVENESS** | Descriptive, generic, or insufficient fanciful distinctiveness |
| **BRAND QUALITY FAILURE** | Survived collision screen but failed ultra-premium/VIP brand standard |
| **PRELIMINARY EXTERNAL SCREEN FAILURE** | Rejected at independent preliminary commercial screening outside repository |

**Do not interpret entries as:** ILLEGAL · INFRINGING · UNREGISTERABLE.

---

## No-recycle policy

The following are **permanently excluded** from future WorkshopOS automated or AI-assisted naming work:

1. Every name in this register
2. **Close spelling variants** (e.g. Lumaro → Lumera, LumaroX, Lumaro.io-style respellings)
3. **Close phonetic derivatives** (e.g. Renlor → Renlore; Cordel → Kordel; Lumet → Lumett)
4. **Single-letter mutations** of rejected finalists intended to bypass prior screening
5. **Trivial morphology swaps** on rejected Round I/II/III patterns (`-var`, `-sund`, `-ven`, `-vel`, `-lund`, `-mast`, `-mald`, `-vast`, crowded `-ix`/`-on`/`-ora`)

Future candidates must be evaluated through the **clearance-first pipeline** documented in [final-commercial-brand-brief.md](final-commercial-brand-brief.md) using [commercial-brand-candidate-template.md](commercial-brand-candidate-template.md).
