# WorkshopOS Commercial Brand Naming Sprint

**STEP 24.2** — Premium brand strategy and finalist preparation  
**Status:** NAMING EXERCISE — NOT LEGAL TRADEMARK CLEARANCE  
**Working / internal name:** WorkshopOS (unchanged)  
**Final commercial brand:** NOT YET SELECTED

---

## Brand strategy

Independent commercial research identified **exact-name WorkshopOS** products active in the automotive workshop software market. WorkshopOS therefore remains an **internal working name** until a more **distinctive** commercial brand is selected and externally cleared.

This sprint prepares a **premium B2B shortlist** for owner and counsel screening. No candidate is legally cleared by this document.

### Brand architecture (preferred)

```
<ONE-WORD DISTINCTIVE BRAND>
<Premium category descriptor / tagline>
```

**Examples of descriptor (not brand):**

- Premium Automotive Operations Platform
- Automotive Operations, Reengineered
- Precision Workshop Intelligence Platform

The **brand word** should not primarily be: Workshop, Garage, Auto, Mechanic, Service, Torque, Repair, Shop, Fleet, or other crowded category stems.

---

## Naming criteria

| Criterion | Requirement |
|-----------|-------------|
| Length | Strong preference **6–9 letters**, one word |
| Structure | No hyphens, numbers, or awkward deliberate misspellings |
| Distinctiveness | Prefer **coined / fanciful** over descriptive/generic |
| Tone | Precision, control, performance, confidence, engineering, intelligence, craft, command, premium technology |
| Visual fit | Must suit graphite/navy, cobalt/cyan, luxury-tech glass UI |
| Languages | Reasonable stability in **English** and **Turkish** pronunciation |
| Avoid | Crypto/gaming/consumer-app cliché; phonetic clones of major automotive/OEM/tool brands; obvious vulgar/negative meanings |
| Product model | Must work for high-ticket B2B source-code commercial product and future SaaS |

## Scoring methodology

Each candidate scored **1–10** on fourteen dimensions. **Weighted total** (max 100):

| Dimension | Weight |
|-----------|-------:|
| Distinctiveness | **×3.0** |
| Premium feel | **×2.5** |
| Memorability | **×2.5** |
| Enterprise credibility | **×2.0** |
| Automotive fit (abstract, not literal) | ×1.0 |
| International (English) pronunciation | ×1.0 |
| Turkish pronunciation | ×1.0 |
| Spelling clarity | ×1.0 |
| Visual / logo potential | ×1.0 |
| Luxury-tech UI fit | ×1.0 |
| Commercial extensibility | ×1.0 |
| Domain flexibility (architectural, not availability) | ×1.0 |
| Future SaaS suitability | ×1.0 |
| Source-product suitability | ×1.0 |

**Maximum weighted score:** 10 × 18.0 = **180** (reported as normalized **/100** in tables below).

### Internal rejection criteria (first filter)

Rejected from initial pool for: generic feel, poor EN/TR pronunciation, obvious automotive cliché, crypto/startup tone, too descriptive, >9 letters or >3 syllables, spelling ambiguity, weak logo geometry, awkward product-family phrasing, or similarity to known software/auto brands (Tekmetric, AutoLeap, Shop-Ware, Mitchell, WorkshopOS, etc.).
