## Decision

| Field | Value |
|-------|-------|
| **Owner score** | /10 or qualitative |
| **Final status** | See statuses below |
| **Decision date** | |
| **Decision by** | |

### Allowed final statuses

| Status | Meaning |
|--------|---------|
| **NEW** | Dossier opened; screening not started |
| **PRELIMINARY SCREENING** | Stages 2–6 in progress |
| **REJECTED** | Failed screening — add to rejected register |
| **COUNSEL REVIEW** | Advanced to formal trademark review |
| **FINALIST** | Survived preliminary + counsel pre-review; owner considering |
| **APPROVED FOR REBRAND** | Owner + counsel approved; rebrand authorized |

### Forbidden statuses

- TRADEMARK SAFE
- LEGALLY CLEAR
- SAFE TO REGISTER
