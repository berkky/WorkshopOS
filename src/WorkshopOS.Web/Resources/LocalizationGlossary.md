# WorkshopOS Localization Glossary (en-US → tr-TR)

Internal terminology map for consistent automotive workshop UI translations.

| English | Turkish | Notes |
|---------|---------|-------|
| Dashboard | Genel Bakış | Primary overview screen |
| Repair Order | İş Emri | Singular; list: İş Emirleri |
| Service Advisor | Servis Danışmanı | Staff role context |
| Technician | Teknisyen | Workshop floor role |
| Inspection / DVI | Araç Kontrolü / DVI | DVI kept as acronym |
| Estimate | Teklif | Customer-facing quote |
| Approval | Onay | Verb/noun in workflow |
| Parts | Parça | Catalog/inventory context |
| Labor | İşçilik | Estimate/invoice line type |
| Inventory Adjustment | Stok Düzeltmesi | Stock movement |
| Invoice | Fatura | Billing document |
| Payment | Ödeme | Workshop-entered payment |
| Customer Portal | Müşteri Portalı | Secure estimate review |
| Appointment | Randevu | Scheduling |
| Vehicle | Araç | Customer asset |
| Work Status | İş Durumu | Technician assignment state |
| Priority | Öncelik | Repair order priority |
| Operations Board | Operasyon Panosu | Kanban-style floor view |
| My Work | İşlerim | Technician view |

Proper names (WorkshopOS, vehicle brands, VIN, part numbers, user-entered data) are never translated.
